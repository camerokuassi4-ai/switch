Comment réinitialiser mon code PIN ?
expand_more
Allez dans Paramètres > Sécurité > Changer mon code PIN. Un code OTP de vérification par SMS vous sera envoyé sur votre numéro de téléphone pour valider le changement.
help
Quels sont les frais de transfert ?
expand_more
Tous les transferts Switch à Switch sont 100% gratuits (0 FCFA). Pour les retraits chez un agent ou les passerelles Mobile Money, un simulateur transparent est disponible sur l'accueil.
help
Comment lier mon compte MTN MoMo / Moov ?
expand_more
Accédez à votre Profil > Moyens de Paiement > Ajouter un compte, sélectionnez votre opérateur (MTN, Moov, Celtiis) et confirmez le code de validation reçu.
