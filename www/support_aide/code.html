Questions Fréquentes (FAQ)

1 Comment faire un dépôt 0% en Agence Switch ?
expand_more
Rendez-vous dans Dépôt de fonds > Dépôt en Agence (0%). Indiquez le montant pour générer un code à 6 chiffres et un QR code. Présentez-le à l'agent d'un Kiosque Switch agréé pour être crédité instantanément sans aucun frais.
2 Comment passer au Niveau 2 (2 000 000 FCFA) ?
expand_more
Allez dans Plafonds & Limites > Passer au Niveau 2. Scannez votre pièce d'identité officielle (CIP ou CNI biométrique) et effectuez la reconnaissance faciale. La validation est automatique par l'ANIP.
3 Comment fonctionnent les Cartes Virtuelles Visa ?
expand_more
Vos cartes virtuelles Visa vous permettent d'acheter sur Netflix, Amazon, Facebook Ads et partout dans le monde en toute sécurité avec 3D-Secure et blocage instantané.
4 Que faire si j'ai oublié mon Code PIN ?
expand_more
Sur l'écran de connexion ou dans Sécurité > Modifier mon Code PIN, cliquez sur « Code PIN oublié ». Un code OTP SMS vous sera envoyé sur votre numéro sécurisé pour en définir un nouveau.
